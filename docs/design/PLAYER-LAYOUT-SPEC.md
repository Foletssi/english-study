# 播放器页面 · 排版定稿（网页端 + 移动端）

> 这份文档定的是**播放器这一页**（`/watch/:id`）的排版结构，覆盖桌面端和移动端两个屏幕，
> 外加点词浮现的词卡。它取代 [LAYOUT-SPEC.md](LAYOUT-SPEC.md) 里 S2 / S4 两节的结构描述 ——
> 目录页（S1 / S3）那一部分不变，仍然以 LAYOUT-SPEC.md 为准。
>
> 所有尺寸取自 `public/assets/tokens.css` 与 `public/assets/app.css`。文档与代码不一致时，
> **以代码为准**，回来改这里。

---

## 0. 这一版改了什么，为什么改

| 项 | 改前 | 改后 | 理由 |
|---|---|---|---|
| 字幕位置 | 视频下方，通栏 | **视频右侧，独立一栏** | 通栏时每行摊到 800px 以上，眼睛横向扫读跨度太大；收进 360px 后每行字数变少、行数变多，反而好读 |
| 字幕滚动 | 跟着页面滚 | **列内独立滚动** | 视频要一直看得见；页面滚动会把视频推走 |
| 词卡 | 占死 300px 一列，常驻留白 | **点词浮出的浮层** | 没点词时那一列是空的，白白吃掉视频宽度 |
| 手机端控制 | 一排胶囊挤在一起 | **模式胶囊带 + 底部控制条，分两层** | 五个胶囊挤一行，每颗都被压到读不清 |
| 播放器按钮图标 | 字符字形 `▶ ❚❚ « »` | **内联 SVG** | 字符不受控：字体没覆盖时回退，同一页在 Windows / macOS / 安卓上长得不一样，基线还会偏 1–2px |

## 1. 桌面端 · 三栏结构

断点 `> 1080px`。设计稿按 1440 × 900 画。

内容区沿用全站规则：`outlet` 最大宽度 **1240px** 居中，左右内边距 **16px**，所以实际可用宽度是
`1240 − 16 × 2 =` **1208px**。

```
┌────────────────────────────┬──────────────┬──────────────┐
│                            │              │              │
│      视频 16:9（524px）     │   字幕流      │   本课信息    │
│                            │   360px      │   280px      │
│                            │              │              │
├────────────────────────────┤   列内独立    ├──────────────┤
│  进度条                     │   滚动        │   快捷键      │
│  控制条                     │              │              │
│  标题 / 副标题              │              │              │
└────────────────────────────┴──────────────┴──────────────┘
         ←———————— 接下来看（通栏）————————→
```

### 1.1 栅格

```css
grid-template-columns: minmax(0, 1fr) 360px 280px;
gap: 22px;   /* var(--space-5) */
```

列宽分配（1208px 可用宽，两处 22px 间距）：

| 列 | 宽度 | 说明 |
|---|---|---|
| 第一列 · 视频 + 控制 | **524px** | `1208 − 360 − 280 − 22 × 2` |
| 第二列 · 字幕流 | **360px** 固定 | 不随窗口伸缩 —— 伸缩会让每行字数忽多忽少 |
| 第三列 · 侧栏 | **280px** 固定 | 与原设计一致 |

> 视频框 524px 宽、16:9，即约 295px 高。这是「字幕优先」的取舍：这是口语学习页，
> 用户大部分时间在读字幕，视频是背景。若你更希望视频大一些，把第二列降到 320px 即可，
> 但 320px 以下中文翻译会开始频繁折行。

### 1.2 第一列内部（竖排，间距 12px）

| 顺序 | 元素 | 规格 |
|---|---|---|
| 1 | 视频框 | 16:9 · 圆角 18px · **恒黑底 #000，不随主题变** |
| 2 | 进度条 | 高 8px · 全圆角 · 三层：下沉灰底 → `--line-strong` 缓冲 → 主色填充 |
| 3 | 控制条 | 见 1.4 |
| 4 | 标题 | 21px / 600 |
| 5 | 副标题 | 13px / `--text-muted` |

进度条的拖拽圆点：14px，白底 + 3px 主色描边，**默认透明，悬停或键盘聚焦时才显形**。

### 1.3 第二列 · 字幕流

固定 360px 宽，`overflow-y: auto`，**独立滚动**，高度贴合左侧视频列（约 470px 后开始滚）。

行结构：

```
┌─────────────────────────────────────────┐
│  01:29   I have a few things to do today.│  ← 英文 15px / 行高 1.75 / 衬线
│          今天有几件事要做。                │  ← 中文 12px / --text-muted
├─────────────────────────────────────────┤  ← 1px 分隔线 --line，最后一行不画
│  01:35   I'm trying to make the most of… │
│          我想充分利用早上的时间。          │
```

| 项 | 值 |
|---|---|
| 时间列宽 | 52px（等宽 12px / `--text-faint`） |
| 行内边距 | **14px × 14px** |
| 行间距 | **4px** |
| 行间分隔线 | 1px `--line`，最后一行不画 |
| 英文正文 | 15px / 行高 1.75 / `--font-read`（Source Serif 4 + 宋体） |
| 中文翻译 | 12px / `--text-muted` / 与英文间距 8px |
| 当前句 | 底色 `--brand-accent-soft` + **左侧 3px 主色竖条** |
| 重点表达 | `--teach-expression` 字色 + `--teach-expression-line` 2px 下划线 |
| 已选中词 | `--teach-word-active-bg` 底色 + `--teach-word-active-underline` 下划线 |

**当前句的那条 3px 左沿是新增的。** 只有底色的话，滚到中间时三层浅色底会分不清哪句是
正在播的；加一条竖线，眼睛一扫就能定位。竖线在行左侧、向内不占时间列的宽度。

**衬线体的理由**：长段连续英文用衬线，字母之间的区分度比无衬线高，读完一屏之后眼睛更省力。

### 1.4 第一列 · 控制条

```
[« 后退]  [▶ 播放]  [» 前进]   6:12 / 13:40          ←—— 弹性空隙 ——→   [1x][单句循环][跟读][盲听][挖空]
  44×44      44×44     44×44      等宽 12px                                    胶囊 6×12px
```

- 左边一组：后退 / 播放 / 前进，各 **44 × 44**（`--tap-min`），图标 20px。
- 时间码紧跟其后：等宽 12px，`--text-muted`，形如 `6:12 / 13:40`。
- **中间是弹性空隙，不是没排满。** 左边是「控制播放」，右边是「控制学习模式」，两组之间
  必须要有一片空白把播放键隔成左侧的焦点。
- 右边一组五颗胶囊：`1x → 单句循环 → 跟读 → 盲听 → 挖空`，顺序固定。
  内边距 6 × 12px，12px 字，全圆角。激活态 = 主色文字 + 主色浅底 + 主色描边。
- **别把它们排成等距** —— 等距之后播放键就不再是焦点。

### 1.5 第三列 · 侧栏

280px，`position: sticky`，吸顶在 `--topbar-h + 22px` 处。

| 卡 | 内容 |
|---|---|
| 本课信息 | 三行左右对齐：难度 / 分类 / 学习进度 |
| 快捷键 | 三行：`空格` 播放暂停、`←` 后退 5 秒、`→` 前进 5 秒 |

（原来的第三张「接下来看」移到下方通栏。放在 280px 窄列里只能排两列，反而挤。）

### 1.6 下方通栏

「接下来看」占满 1208px，子卡 `repeat(auto-fill, minmax(180px, 1fr))`，最多 4 张。
每张 = 13px 标题 + 12px 提示（下一课 / 已学 82% / 未开始）。

### 1.7 断点收缩

| 断点 | 处置 |
|---|---|
| `> 1280px` | 三栏（本档） |
| `1080 – 1280px` | 侧栏收起，两栏：视频 `1fr` + 字幕 360px |
| `860 – 1080px` | 两栏不变，内容区内边距收窄 |
| `≤ 860px` | 走移动端（第 3 节），三栏全部塌成单列 |

## 2. 词卡

点字幕里的重点词浮出。**不再占常驻的一列** —— 没点词时那一列是空的。

### 2.1 结构（宽 340px）

```
┌─────────────────────────────────────┐
│  play it by ear              🔊  ✕  │  ← 词头 21px/600 · 语音钮 36×36 · 关闭钮 36×36
│  /pleɪ ɪt baɪ ɪr/                   │  ← 音标 等宽 12px / --text-muted
│  ⬤ 习语                             │  ← 类型胶囊 12px
│  ─────────────────────────────────  │  ← 1px 分隔线
│  核心释义                            │  ← 11px / --text-faint
│  随机应变；看情况再决定               │  ← 15px 正文
│                                     │
│  语境理解                            │
│  先不把计划定死，到时候再看怎么安排。  │
│                                     │
│  ┌─────────────────────────────┐    │  ← 下沉底 --surface-sunken / 圆角 13px
│  │ We don't need a fixed plan. │    │
│  │ Let's play it by ear.       │    │  ← 目标短语 --teach-expression 加下划线
│  │ 不用提前定死计划，到时候再看吧。│    │  ← 12px / --text-muted
│  └─────────────────────────────┘    │
│                                     │
│  ▷ 播放原句   ⧉ 复制   [＋ 加入生词本] │  ← 底排，主按钮最右
└─────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 卡片 | 340px · 圆角 18px · 白底 · 内边距 16px · 阴影 `0 8px 28px rgba(15,27,45,.14)` |
| 词头 | 21px / 600 |
| 音标 | 等宽 12px / `--text-muted`，与词头同行、基线对齐、间距 8px |
| 类型胶囊 | 12px，如「习语 / 短语 / 名词」，底色 `--accent-soft` 字色 `--accent-strong` |
| 分组标签 | 11px / `--text-faint`，上方间距 14px |
| 释义正文 | 15px / 行高 1.55 |
| 例句块 | 底色 `--surface-sunken` · 圆角 13px · 内边距 12px |
| 底部按钮 | 幽灵按钮 13px；主按钮（加入生词本）主色实底，靠最右 |

### 2.2 位置

| 屏幕 | 位置 |
|---|---|
| 桌面 | **贴着被点击的那个词浮出**：优先出现在词的下方 8px，左边缘与词左对齐；若下方空间不足则翻到上方 8px；若右边缘超出内容区则向左贴齐 |
| 移动 | **从底部滑上来的面板**：占满宽度、顶部圆角 18px、顶部一根 36 × 4px 拖拽把手、底部留 `safe-area-inset-bottom`。窄屏上没有空间给它贴着词浮 |

桌面出现浮层时，词卡覆盖在字幕列之上，**字幕列不重排**（否则浮出的瞬间整列文字跳动）。
浮层外的点击 = 关闭；`Esc` 也关闭。

### 2.3 发音按钮的四个状态

并列画四颗，尺寸全部锁 36 × 36、图标 20px —— **换状态时按钮不能跳**。

| 状态 | 外观 | 触发 |
|---|---|---|
| 发音 | 喇叭线性图标 | 默认 |
| 加载中 | 喇叭位置换成一圈虚点，旋转 | 点了、音频还没开始 |
| 播放中 | 喇叭图标 + 主色实底圆 | 正在响 |
| 重试 | 圆形箭头图标 | 加载失败 |

### 2.4 两个新按钮

| 按钮 | 能否实现 |
|---|---|
| 播放原句 | **能**。播单词所在那句的起止时间 —— 现有「跟读」功能已经是这套逻辑 |
| 复制 | **能**。拷贝整句英文 + 中文 |

### 2.5 待决

**「核心释义 / 语境理解」目前只有一个 `gloss` 字段**，拆成两段需要后端多给一个字段。
在两段都定下来之前，词卡只渲染「核心释义」一段，「语境理解」整块不出现（不留空标签）。

## 3. 移动端 · 五段结构

断点 `≤ 860px`。设计稿按 390 × 844 画。

```
┌──────────────────────────────┐
│ ← 忙碌的一天生活 Vlog        ☀ │  A 顶栏 56px，sticky
├──────────────────────────────┤
│                              │
│        视频 16:9              │  B 全宽，无圆角
│                              │
│  01:35 / 10:43          ⛶   │    时间码 + 全屏钮压在视频右下角
├──────────────────────────────┤
│ ↻单句循环  ↺跟读  🎧盲听  ▢挖空 │  C 模式胶囊带，横向可滑
├──────────────────────────────┤
│ I have a few things to do…   │
│ 今天有几件事要做。      🔊 ☆ │  D 字幕流，占满剩余高度，独立滚动
│ ─────────────────────────    │
│ I'm trying to make the most… │
│ 我想充分利用早上的时间。 🔊 ☆ │
├──────────────────────────────┤
│ 1x   循环   跟读   盲听   挖空   ▶   ⋯ │  E 底部控制条 64px，sticky
└──────────────────────────────┘
```

### A · 顶栏 56px

| 位置 | 元素 | 尺寸 |
|---|---|---|
| 左 12px | 返回箭头 | 44 × 44 触摸区，图标 24px |
| 箭头右 8px | 视频标题 | 15px / 500，单行截断 |
| 右 12px | 主题按钮 | 44 × 44，图标 20px |

### B · 视频区

16:9 全宽，**不加圆角**（贴边更沉浸）。
右下角压一层横向排列的：时间码（等宽 12px / 白字带暗底）+ 全屏图标（20px）。
全屏沿用浏览器原生实现，不自绘控制层。

### C · 模式胶囊带

一条横向滚动条，高 44px，左右内边距 12px，胶囊间距 8px。
四颗：`单句循环 → 跟读 → 盲听 → 挖空`，顺序与桌面端一致。
激活态同桌面端（主色字 + 主色浅底 + 主色描边）。

**这里故意不放播放键。** 播放键归 E 段的 56px 圆钮 —— 两处都放的话，
同一动作有两个入口，用户会犹豫该点哪个。

### D · 字幕流

占满 A–C 与 E 之间的全部剩余高度，独立滚动。行结构与桌面端同，只改这几处：

| 项 | 桌面端 | 移动端 |
|---|---|---|
| 时间列 | 52px | 52px（不变） |
| 英文正文 | 15px | **14px** |
| 行内边距 | 14 × 14px | **12 × 12px** |
| 行右端 | 无 | **两颗 18px 图标：喇叭 / 星标** |
| 中文翻译 | 12px | 12px（不变） |

行右端那两颗是本版新增：喇叭念这一句，星标收藏这一句。**没有星标时整颗不画**，
不留空位（与顶栏 VIP 徽标同一条规则）。

### E · 底部控制条 64px

```
┌──────────────────────────────────────────┐
│  1x   循环   跟读   盲听   挖空     ▶    ⋯ │
└──────────────────────────────────────────┘
```

- 左侧：五颗文字胶囊，与 C 段**指向同一批状态**，两处必须同步。
- 中间：**56px 主色实底圆形播放钮**，白色实心三角 24px。整条里唯一的实心图标。
- 右侧：`⋯` 44 × 44，展开菜单：跟读 / 挖空 / 播放速度。
- 底部叠 `env(safe-area-inset-bottom)`，否则 iPhone 上被 Home 条压住。
- 白底 + 顶部 1px `--line` 描边，`z-index: 50`。

**参考图里还有一条底部功能条**（重点词 28 / 生词本 3 / 标记已学 / 视频目录）。
**这一版不画。** 两条底栏加起来 112px，手机上太高，会吃掉两行字幕。
「生词本」和「标记已学」收进 E 段右侧的 `⋯` 菜单里。

## 4. 图标清单

统一规则：**24 × 24 网格、2px 描边、圆角端点、线性。只有播放三角是实心。**
混用实心与线框，某颗会在 18px 下糊成一团，或看起来比别的重。

### 4.1 已有的（`src/ui/icons.js` 里能直接取）

| 名称 | 形状 | 用在哪 |
|---|---|---|
| `play` | 实心三角 | 播放钮 |
| `arrowLeft` | 左尖角 | 后退 / 返回 |
| `arrowRight` | 右尖角 | 前进 |
| `close` | 交叉 | 词卡关闭 |
| `search` | 放大镜 | 顶栏搜索 |
| `sun` / `moon` / `flame` | 主题三态 | 顶栏主题钮 |
| `home` `library` `plan` `vocabulary` `account` | 标签栏五项 | 底部标签栏 |

### 4.2 要新画的（5 颗）

| 名称 | 形状描述 | 用在哪 |
|---|---|---|
| `pause` | 两条竖杠 | 播放中状态的播放钮（现在用的是字符 `❚❚`） |
| `speaker` | 喇叭 + 两道弧线声波 | 词卡发音钮、字幕行发音 |
| `replay` | 一个顺时针开口圆 + 顶点箭头 | 词卡「重试」状态、单句循环 |
| `star` | 五角星轮廓（线性，非实心） | 字幕行收藏 |
| `more` | 三个横向圆点 | 底部控制条「更多」 |

> `pause` 画成**两条竖杠**而不是实心双竖条：整排里只有播放三角是实心，
> 暂停换成实心会让它在切换的一瞬间比邻居重一档。

### 6.1 共用开头（每次都带上）
